Bulk Import Projects

Instructions

  1. Prepare an Excel file (.xlsx, .xls) or JSON file
  2. Each row/project must include: title, authors, program, year
  3. Optional but recommended: adviser, abstract, keywords, topics, status
  4. Click "Choose File" and select your Excel or JSON file
  5. Review the preview and click "Import Projects"
Download Template Files

Recommended: Download the Excel template, edit it with your data, then upload it here.
